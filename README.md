# 奶蛙坦克大战

一个用 C11 和 raylib 6.2 编写的 Windows 单人坦克游戏。控制黄色像素奶蛙保护基地、消灭敌人，也可以打开 BFS 观察界面，查看寻路距离场和敌人链表。

这是《奶蛙坦克大战》的三关课程版，和完整版《奶蛙危机：哈工大防线》分开维护。仓库包含源码、资源和自动测试；先按下方说明编译，再运行生成的 `TankBattle90.exe`，保留同目录的 `assets`。

玩家是黄色像素奶蛙，敌人为蓝、绿、灰白、粉色，基地是一颗黄星。共三关，每关 8 个敌人，同屏最多 4 个。第一关仅普通敌人；第二关为普通、快速和速射敌人，没有重型；第三关为快速、速射和重型敌人，没有普通。保护基地并消灭全部敌人后过关；基地中弹或生命耗尽结束。初始 3 条生命，死亡后复活。

| 关卡 | 普通 | 快速 | 速射 | 重型 | 合计 |
| --- | --- | --- | --- | --- | --- |
| 第一关 | 8 | 0 | 0 | 0 | 8 |
| 第二关 | 3 | 3 | 2 | 0 | 8 |
| 第三关 | 0 | 3 | 2 | 3 | 8 |

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 移动、转向；菜单选择 |
| J / 空格 | 沿当前朝向开炮 |
| Enter | 确认、开始本关、进入下一关 |
| Esc | 暂停、继续、返回 |
| B | 打开或关闭寻路视图 |
| N / R | 寻路视图展开一层 / 重新搜索 |
| M | 开关音效 |

初始同时只能有一发己方子弹。星星逐级提高弹速、增加到两发、允许拆除钢板。砖墙分块破坏；河流阻挡移动，但子弹可以穿过；树林遮挡单位。六种道具分别为星星、手雷、头盔、铁锹、时钟和生命。手雷清敌不计击杀分，道具本身计 500 分。战绩结束时追加到程序目录的 `records.txt`，按分数稳定排序显示前十名；保存失败可按 S 重试。三关合计最多击毁 24 个敌人。

## 数据结构与算法

敌人使用动态单链表。移动和 BFS 共用 25×25 个位置，每步 20 像素，按实际墙块检查 32 像素车体。BFS 使用容量 625 的顺序队列，建立基地和玩家两个共享距离场；砖墙可纳入规划，敌人到达前先拆墙。B 键展示真实的基地距离场、逐层队列、路线和敌人链表。距离是网格步数，不包含拆墙耗时和其他敌人的临时阻挡。

排行榜使用稳定插入排序，地图和战绩使用文本文件读写。BFS 实现在 `src/algorithms.c`，链表与战斗规则在 `src/game.c`。

## 构建

把 MinGW-w64 的 bin 加入 PATH，执行 `build.bat` 或 `make`。raylib 头文件已包含在 `lib/include` 中；请自行获取与工具链兼容的 Windows x64 MinGW-w64 raylib 6.2 静态库，将 `libraylib.a` 放入 `lib/lib/` 后编译（库下载与构建见 https://github.com/raysan5/raylib ）。仓库不分发该预编译静态库；游戏运行不需要安装 Python 或 raylib DLL。字体、地图和精灵均已有生成结果，正常编译不需要运行 Python 工具。

自动验证需要 Python 3.9 及以上，在 Source 目录执行：

```text
python tools/verify.py --compiler-dir "C:/工具链/bin" --output work/check01
```

将工具链路径改为本机 MinGW-w64 GCC 的 bin 目录。输出目录必须尚不存在。脚本严格编译游戏、核心、链表回归、画面和输入测试，记录命令、SHA256 和实际结果。全部自动运行使用 `--test-hidden`，EXE、资源和运行目录均在 work 下隔离，不创建玩家战绩。`--test-hidden --test-interactive` 仅用于隔离目录的可视交互检查，仍不保存战绩。

## 参考与范围

玩法与前三关的地图参考 newagebegins/BattleCity，MIT 许可见 `docs/BATTLECITY_MIT_LICENSE.txt`。本版用 C 重新实现，增加共享 BFS 和观察界面，保留自己的像素奶蛙；敌人总数与出场表按课程版要求调整为上表。它是三个关卡的课程版本，未实现参考仓库的全部关卡、双人模式或地图编辑器。

游戏优先使用 Windows 自带的黑体（SimHei），未安装时使用随包提供的 Noto Sans SC 常规字重子集。Windows 字体不随包分发；后备字体 OFL 见 `assets/font/OFL.txt`，raylib 许可见 `lib/RAYLIB_LICENSE.txt`。游戏使用 raylib 图形、输入、音频接口，不是仅用 C 标准库的控制台程序。

## 目录

```text
src/        游戏规则、界面、地图、BFS和战绩处理
tests/      核心规则、链表关卡、输入音频与画面测试
assets/     精灵、三张地图及后备字体
lib/        raylib头文件、静态库放置说明和许可
tools/      隔离编译与验证脚本
docs/       参考来源和测试说明
```

## 已知范围

目前只核验Windows + MinGW-w64构建；不承诺Linux、macOS或MSVC直接可用。没有双人模式、地图编辑器或完整经典关卡集。BFS显示的是网格距离，不计拆墙耗时，也不保证避开其他敌人的临时占位。测试通过不等于不存在缺陷。

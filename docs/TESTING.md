# 验证方法

在仓库根目录运行：

```text
python tools/verify.py --compiler-dir "C:/工具链/bin" --output work/check01
```

需要Python 3.9或更新版本和MinGW-w64 GCC。输出目录必须不存在。脚本严格编译游戏及四套测试，使用隔离EXE与工作目录，并带`--test-hidden`运行，不应生成玩家战绩。

覆盖核心规则、链表删除和关卡调度、API层按键注入、音效对象与画面布局。API输入不是操作系统键盘实玩；脚本切换关卡不是正常生命通关；音效对象检查不能代替试听。用户已确认亲自通过原提交版三关。

本地公开候选的实际测试结果由外部审阅说明记录，未把带个人路径的原始日志放入仓库。
